# 批量匯入功能使用說明

## 功能介紹

現在你可以一次性匯入數百個字詞，無需逐個手動輸入！支援多種格式：
- **CSV 檔案** - Excel 兼容，最簡單
- **Excel 檔案** (.xlsx) - 每個工作表 = 一個章節
- **文字檔** (.txt) - 人類可讀的格式
- **JSON 檔案** - 完整的內容包(含元數據)

---

## 快速開始

### 步驟 1: 準備您的內容

#### 選項 A: 使用 CSV (推薦)

在 Excel 或 Google Sheets 中創建表格:

| Chapter | Front | Back | Pronunciation | Type | Tags |
|---------|-------|------|--------------|------|------|
| 第一課 | Shirt | 襯衫 | saam1 | word | 衣服,日常 |
| 第一課 | Pants | 褲子 | fu3 zi2 | word | 衣服 |
| 第二課 | Hello | 你好 | nei5 hou2 | phrase | 問候 |

**重要提示:**
- 第一行必須是標題行
- `Front` 欄是必須的
- 其他欄可選
- 保存為 `.csv` 格式

#### 選項 B: 使用文字檔

創建 `.txt` 檔案:

```
LIBRARY: 小學二年級詞彙
DESCRIPTION: 適合小學二年級學生的常用詞彙
CATEGORY: 詞彙 (Vocabulary)
TAGS: 小學, 基礎, 日常
LANGUAGE: zh-HK
LEVEL: beginner

===CHAPTER: 第一課 - 衣服===

Shirt | 襯衫 | saam1 | word | 衣服
Pants | 褲子 | fu3 zi2 | word | 衣服

===CHAPTER: 第二課 - 問候===

Hello | 你好 | nei5 hou2 | phrase | 問候
```

### 步驟 2: 匯入內容

1. 打開 SpeedyRead
2. 點擊底部的 **➕** (新增)
3. 選擇 **📥 批量匯入**
4. 填寫內容資訊:
   - **名稱** (必填): 例如 "小學二年級詞彙"
   - **描述**: 簡短說明用途
   - **分類**: 選擇或自訂
   - **標籤**: 添加相關標籤
   - **語言**: 選擇語言
   - **難度**: 初級/中級/高級
5. 拖放檔案或點擊 "選擇檔案"
6. **預覽** 匯入內容:
   - 檢查章節數量
   - 檢查字詞數量
   - 查看前幾個範例
7. 確認無誤後，點擊 **✓ 確認匯入**

### 步驟 3: 查看匯入結果

- 匯入成功後會自動跳轉到書庫頁面
- 您會看到新創建的分類
- 所有字詞已按章節組織好
- 可以立即開始學習！

## 檔案格式詳解

### CSV 格式

**必填欄位:**
- `Front` - 正面文字(例如英文單詞)

**可選欄位:**
- `Chapter` - 章節名稱(例如 "第一課")
- `Back` - 背面文字(例如中文翻譯)
- `Pronunciation` - 發音/拼音
- `Type` - 類型 (word/phrase/sentence)
- `Tags` - 標籤，用逗號分隔

**範例下載:** `/public/sample-import.csv`

### Excel 格式

- **每個工作表** = 一個章節
- 工作表名稱 = 章節名稱
- 第一行 = 標題行
- 欄位與 CSV 相同

**優點:** 
- 可視化編輯
- 支援多章節
- 易於組織

### 文字格式

**結構:**
```
LIBRARY: [內容名稱]
DESCRIPTION: [描述]
CATEGORY: [分類]
TAGS: [標籤1], [標籤2]
LANGUAGE: [語言代碼]
LEVEL: [難度]

===CHAPTER: [章節名稱]===

[Front] | [Back] | [Pronunciation] | [Type] | [Tags]
...

===CHAPTER: [另一章節]===

[Front] | [Back] | [Pronunciation] | [Type] | [Tags]
...
```

**優點:**
- 人類可讀
- 易於版本控制
- 可用任何文字編輯器

### JSON 格式

完整的內容包格式，包含所有元數據:

```json
{
  "version": "1.0",
  "metadata": {
    "name": "小學二年級詞彙",
    "description": "適合小學二年級學生",
    "category": "詞彙 (Vocabulary)",
    "tags": ["小學", "基礎"],
    "language": "zh-HK",
    "level": "beginner",
    "author": "張老師"
  },
  "chapters": [
    {
      "name": "第一課",
      "words": [
        {
          "front": "Shirt",
          "back": "襯衫",
          "pronunciation": "saam1",
          "type": "word",
          "tags": ["衣服"]
        }
      ]
    }
  ]
}
```

**優點:**
- 完整的元數據
- 適合分享/交換
- 未來市場格式

## 常見問題

### Q: 可以匯入多少個字詞?
**A:** 理論上無限制! 實際測試 1000+ 字詞沒問題。建議單次不超過 5000 個以保證性能。

### Q: 匯入失敗怎麼辦?
**A:** 檢查:
1. 檔案格式是否正確
2. 第一行是否為標題
3. `Front` 欄是否存在且有內容
4. 檔案編碼是否為 UTF-8
5. 查看錯誤訊息中的具體問題

### Q: 可以更新已匯入的內容嗎?
**A:** 目前需要:
1. 匯出內容
2. 修改檔案
3. 刪除舊內容
4. 重新匯入

(未來版本會支援直接更新)

### Q: 匯入的內容會覆蓋現有內容嗎?
**A:** 不會! 每次匯入都會創建新的分類，不會影響現有內容。

### Q: 如何與他人分享我的內容?
**A:** 
1. 到書庫頁面
2. 選擇要分享的分類
3. 點擊 "匯出" 按鈕
4. 選擇格式 (推薦 JSON 或 CSV)
5. 將檔案發送給對方
6. 對方可以用批量匯入功能導入

## 提示和技巧

### 💡 最佳實踐

1. **先從小範例開始**
   - 創建 5-10 個字詞的測試檔案
   - 確認格式正確後再製作完整內容

2. **使用描述性的章節名稱**
   - ✅ "第一課 - 問候語"
   - ❌ "第一課"

3. **善用標籤**
   - 添加多個相關標籤方便搜尋
   - 例如: "小學, 二年級, 詞彙, 日常, 基礎"

4. **填寫完整的元數據**
   - 幫助未來組織和搜尋
   - 為市場功能做準備

5. **備份重要內容**
   - 定期匯出為 JSON 檔保存
   - 可作為版本控制

### ⚡ 效率提升

**使用 Excel/Google Sheets:**
1. 利用公式自動填充
2. 複製粘貼大量內容
3. 用篩選功能檢查數據
4. 直接保存為 CSV

**批量處理:**
1. 一次準備多個章節
2. 使用 Excel 多工作表功能
3. 保存為模板重複使用

**內容來源:**
- 從課本複製貼上
- 從網上資源整理
- 自己編寫教材
- 與其他老師交換
